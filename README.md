# 🎮 Kowkun Games

Веб-платформа с коллекцией классических браузерных мини-игр, системой авторизации, личными заметками и глобальной таблицей рекордов.

🔗 **[Играть онлайн](https://pota9.github.io/kowkun-games/)** 

---

## 🕹️ Игровая коллекция

На платформе доступно **13 игр и интерактивных режимов** на любой вкус:

### Головоломки и логика
* **2048** — складывайте числа и соберите заветную плитку 2048.
* **Судоку** — классическая числовая головоломка для тренировки ума *(с учётом времени прохождения)*.
* **Вордли** — угадайте секретное слово из 5 букв за 6 попыток.
* **Пятнашки** — соберите числа на поле по порядку.
* **Сапёр** — разминируйте поле, полагаясь на логику и внимание к деталям.

### Аркады и на реакцию
* **Змейка** — легендарная аркада с подсчётом очков.
* **Тетрис** — заполняйте линии падающими блоками и не дайте им достичь верха.
* **Лабиринт** — гонка на время через случайные запутанные лабиринты.

### Настольные и карточные
* **Шахматы** — классическое сражение умов на 64 клетках.
* **Шашки** — тактическая битва за звание короля доски.
* **Четыре масти** — уникальная карточная битва с четырьмя разными стилями игры.

### Симуляторы и релакс
* **Жизнь (Game of Life)** — создайте свою вселенную и наблюдайте за эволюцией клеточного автомата.
* **Заставка** — умиротворяющая анимация с интерактивными элементами и двумя режимами релакса.

## ✨ Основные возможности

* **👤 Аккаунты игроков:** регистрация и авторизация пользователей.
* **🏆 Таблица рекордов:** глобальный топ-5 лучших игроков в ключевых дисциплинах (*Тетрис, Змейка, Четыре масти, Судоку*), а также отображение личных рекордов прямо на карточках игр[cite: 2, 3].
* **📝 Заметки:** встроенный раздел для личных заметок авторизованного пользователя.
* **📱 Адаптивный интерфейс:** современный минималистичный дизайн с удобной навигацией.

## 🛠️ Технологии и структура

Проект собран в виде статического веб-приложения (Next.js Static Export) и готов к деплою на **GitHub Pages** или **Netlify**:

* **Frontend:** Next.js (`_next/static`), HTML5, CSS3, JavaScript
* **Backend / Auth / DB:** Firebase (`firebase.html`)
* **Деплой:** настроены `.nojekyll` для корректной работы на GitHub Pages и `_redirects` для маршрутизации на Netlify.

### Основные страницы репозитория
* `index.html` — главная страница с каталогом игр
* `records.html` — таблица лидеров
* `auth.html` / `regi.html` — вход и регистрация
* `2048.html`, `Snake.html`, `Tetromino.html`, `Wordle.html`, `Chess.html`, `Sudoku.html` и др. — страницы отдельных игр
