# 🎮 Kowkun Games

Веб-платформа с коллекцией классических браузерных мини-игр, системой авторизации, личными заметками и глобальной таблицей рекордов[cite: 1, 2, 3, 4, 5].

🔗 **[Играть онлайн](https://pota9.github.io/kowkun-games/)** 

---

## 🕹️ Игровая коллекция

На платформе доступно **13 игр и интерактивных режимов** на любой вкус[cite: 1, 2, 3]:

### Головоломки и логика
* **2048** — складывайте числа и соберите заветную плитку 2048[cite: 1].
* **Судоку** — классическая числовая головоломка для тренировки ума *(с учётом времени прохождения)*[cite: 3].
* **Вордли** — угадайте секретное слово из 5 букв за 6 попыток[cite: 1].
* **Пятнашки** — соберите числа на поле по порядку[cite: 1].
* **Сапёр** — разминируйте поле, полагаясь на логику и внимание к деталям[cite: 1].

### Аркады и на реакцию
* **Змейка** — легендарная аркада с подсчётом очков[cite: 2, 3].
* **Тетрис** — заполняйте линии падающими блоками и не дайте им достичь верха[cite: 2, 3].
* **Лабиринт** — гонка на время через случайные запутанные лабиринты[cite: 2].

### Настольные и карточные
* **Шахматы** — классическое сражение умов на 64 клетках[cite: 2].
* **Шашки** — тактическая битва за звание короля доски[cite: 2].
* **Четыре масти** — уникальная карточная битва с четырьмя разными стилями игры[cite: 2, 3].

### Симуляторы и релакс
* **Жизнь (Game of Life)** — создайте свою вселенную и наблюдайте за эволюцией клеточного автомата[cite: 1].
* **Заставка** — умиротворяющая анимация с интерактивными элементами и двумя режимами релакса[cite: 1].

## ✨ Основные возможности

* **👤 Аккаунты игроков:** регистрация и авторизация пользователей[cite: 1, 4].
* **🏆 Таблица рекордов:** глобальный топ-5 лучших игроков в ключевых дисциплинах (*Тетрис, Змейка, Четыре масти, Судоку*)[cite: 5], а также отображение личных рекордов прямо на карточках игр[cite: 2, 3].
* **📝 Заметки:** встроенный раздел для личных заметок авторизованного пользователя[cite: 1].
* **📱 Адаптивный интерфейс:** современный минималистичный дизайн с удобной навигацией[cite: 1, 2, 3, 5].

## 🛠️ Технологии и структура

Проект собран в виде статического веб-приложения (Next.js Static Export) и готов к деплою на **GitHub Pages** или **Netlify**[cite: 4]:

* **Frontend:** Next.js (`_next/static`), HTML5, CSS3, JavaScript[cite: 4]
* **Backend / Auth / DB:** Firebase (`firebase.html`)[cite: 4]
* **Деплой:** настроены `.nojekyll` для корректной работы на GitHub Pages и `_redirects` для маршрутизации на Netlify[cite: 4].

### Основные страницы репозитория
* `index.html` — главная страница с каталогом игр[cite: 1, 4]
* `records.html` — таблица лидеров[cite: 4, 5]
* `auth.html` / `regi.html` — вход и регистрация[cite: 4]
* `2048.html`, `Snake.html`, `Tetromino.html`, `Wordle.html`, `Chess.html`, `Sudoku.html` и др. — страницы отдельных игр[cite: 4]
